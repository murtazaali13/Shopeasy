# ShopEasy - Online Shopping Website

## 1. Project Introduction
ShopEasy is an online shopping website designed to allow
customers to browse products, search by category, and
manage their shopping orders.

## 2. Project Objectives
- Create a user-friendly shopping website.
- Display products with names, prices, and descriptions.
- Provide user registration and login.
- Implement a shopping cart and checkout.
- Manage products and orders through an admin dashboard.

## 3. Main Features
1. Home Page
2. Product Catalogue
3. Search and Categories
4. User Registration and Login
5. Shopping Cart
6. Checkout and Orders
7. Admin Dashboard

## 4. Technologies
- HTML - Website structure
- CSS - Website styling
- JavaScript - Interactive features
- Java - Backend processing
- MySQL - Database
- Apache Tomcat - Java web application server
- Git and GitHub - Version control
- Visual Studio Code - Code editor

## 5. Development Method
The project will be developed in stages.
Each day's work will be documented and committed
to GitHub.
